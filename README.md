### 🚀 Featured Projects

| Project | What it does | Stack |
|---|---|---|
| [**Hybrid Search RAG**](https://github.com/aasheeeeesh/Hybrid-Search-RAG) | Retrieval over 556 GitLab Handbook files that fuses BM25 and dense search with Reciprocal Rank Fusion. Recall@5: **71.4%** hybrid, 57.1% BM25, 64.3% dense. | Python, rank-bm25, bge-small-en-v1.5, ChromaDB |
| [**DermAssist**](https://github.com/aasheeeeesh/DermAssist) | Interpretable melanoma classifier on frozen ResNet50 embeddings with Captum occlusion heatmaps. **88.6%** accuracy, **0.95** AUC-ROC. | Python, PyTorch, scikit-learn, Streamlit |
| [**Campus Financial Operations System**](https://github.com/aasheeeeesh/campus-financial-operations-system) | Role-based budget system where SQL triggers block overspending, blacklisted vendors, and late expenses, even if the API is bypassed. | React, Node.js, Express, MariaDB, JWT |
| [**University ERP**](https://github.com/aasheeeeesh/FullStack_ERP) | Java desktop ERP with three user roles and a two-database design that separates authentication from ERP data. | Java, Swing, JDBC, MariaDB |
| [**NBA Playing Time Model**](https://github.com/aasheeeeesh/NBA-model) | Predicts minutes played with a stacked ensemble tuned by Hyperopt. **94.20%** R², 1.65 MAE. | Python, scikit-learn, Hyperopt |
